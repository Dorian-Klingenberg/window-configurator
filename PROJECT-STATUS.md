# WindowConfigurator Status

## Current product context

WindowConfigurator has an established backend-oriented configuration platform:
session persistence, server-side catalog resolution, validation, pricing,
tenant scoping, API-key handling, webhook delivery, retry processing, and demo
host applications are present in the repository. The existing Knockout-based
configurator remains the current user interface.

The product direction is captured in [product-direction.md](./product-direction.md).
Architecture decisions and their rationale are recorded in [adr/](./adr/).

## Historical context

The prior phase roadmap and methodology experiment records were moved intact to
[the governance reset archive](./archive/2026-11-agent-governance-reset/README.md).
They explain how the repository reached its current state but do not prescribe
the method for future work.
